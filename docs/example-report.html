What this establishes — and what it does not

Uniform-width unsigned bitvectors; wrapping arithmetic; logical right shift; overshift yields zero. Not C/LLVM semantics.

Only these expressions and declared input ranges; not the generating program. The solver and translation are trusted; no independently checkable proof certificate is emitted. A counterexample is not necessarily the smallest one. This report contains input expressions and witness values.
